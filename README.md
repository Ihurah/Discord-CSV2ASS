# Discord CSV2ASS

Discord のチャットログ CSV を、動画編集や字幕焼き付けに使える ASS 字幕ファイルへ変換する Windows 向けデスクトップアプリ。

[DiscordChatExporter](https://github.com/tyrrrz/discordchatexporter) で書き出した CSV を読み込み、流れるコメント風の字幕をプレビューしながら調整できます。

## できること

- [DiscordChatExporter](https://github.com/tyrrrz/discordchatexporter) の CSV を読み込んで ASS ファイルへ変換
- フォント、文字サイズ、色、太字、影、表示時間の調整
- コメントを流す高さや開始時刻の調整
- プレビューを見ながら見た目を確認
- サンプルテキストを自由に編集し、改行・通常絵文字・登録済み画像を通常／拡大プレビューで確認（編集内容は再起動後も保持）
- 生成した ASS を保存して [HandBrake](https://handbrake.fr/downloads.php) などで焼き付け
- `:apple:` などの絵文字名を通常の絵文字へ自動変換（オフライン対応）
- 任意の文字列にPNG・JPEG・WebP・GIFを登録し、独自の絵文字として使用
- Discord絵文字の画像やGIFを、ファイルまたは画像URLから登録
- アプリ内でコメント・画像・動くGIFを動画へ焼き付け、MP4で保存

## 使い方

### 画面のタブ

Fluent UI v9のタブで作業を切り替えます。タブを移動しても入力内容や選択したファイルは保持されます。

| タブ | 内容 |
| --- | --- |
| コメント設定 | CSV・XMLの読み込み、基本設定、文字色・縁取り・影、ASS保存 |
| プレビュー | 大きなプレビュー、背景色・画像、サンプルテキストの編集 |
| 絵文字 | 登録済み画像の一覧、ファイル・URLからの追加、変換確認 |
| 焼き付け | 元動画の選択、解像度・エンコーダー・fps・画質・速度、動画保存 |

「コメント設定」には「基本設定」「文字・縁取り・影」の切り替えもあります。画面はライトテーマで表示します。設定と最後に開いたタブはこのPCに保存します。

### 1. DiscordChatExporter で CSV を用意する

まず、Discord のログを CSV 形式で出力します。

1. [DiscordChatExporter](https://github.com/tyrrrz/discordchatexporter) を起動する
2. 出力したいサーバーやチャンネルを選ぶ
3. CSV で EXPORT する
4. 任意の保存先に CSV を保存する

このアプリは、[DiscordChatExporter](https://github.com/tyrrrz/discordchatexporter) から出力した CSV を前提にしています。

### 2. このアプリで CSV を読み込む

1. `Discord CSV2ASS` を起動する
2. 「コメント設定」タブのファイル選択ボタンから、先ほど保存した CSV を読み込む
3. プレビューを見ながら表示設定を調整する
4. `ASSファイルを生成して保存` を押す
5. 保存先を選んで `.ass` ファイルを書き出す

### 3. 動画に字幕を反映する

アプリ内で焼き付ける場合:

1. CSVまたはニコニコ形式XMLを読み込み、開始時刻・見た目を調整する
2. 必要に応じて「絵文字」タブの追加フォームへ文字列を入力し、追加方法の選択欄で「ファイル」または「URL」を選んで登録する
3. 「焼き付け」タブの「元動画を選択」で動画を選ぶ
4. 出力解像度、動画エンコーダー、フレームレート（ソースと同じ / 5〜120 fps）、画質（High / Medium / Low）、エンコード速度を選ぶ
5. 「MP4を生成して保存」など、選択した保存形式のボタンを押して保存先を選ぶ

初期値はH.264（x264）/ AACのMP4です。エンコーダーに応じて保存形式・音声方式を自動で切り替えます。

| 動画エンコーダー | 保存形式 | 音声 |
| --- | --- | --- |
| H.264（x264、10-bit含む）、H.265（x265、10/12-bit含む） | MP4 | AAC |
| AV1（AOM、10-bit含む） | MP4 | AAC |
| NVIDIA NVENC / AMD AMF / Intel QSVのH.264・H.265・AV1 | MP4 | AAC |
| VP8 / VP9（VP9は10-bit含む） | WebM | Opus |
| FFV1（ロスレス） | MKV | FLAC |
| MPEG-2 | MKV | AAC |
| MPEG-4 | MP4 | AAC |

起動時に同梱FFmpegの対応ピクセル形式と1フレームの試験エンコードを確認し、利用できる方式だけを選択肢に表示します。対応GPU・ドライバーがない方式や未対応のビット深度は非表示にします。以前の設定が利用できない場合は案内を表示し、利用できる方式に切り替えます。判定は720p・30fpsでの初期化確認のため、GPUによっては高い解像度・fpsで出力できない場合があります。その場合は別のエンコーダーや出力設定を選んでください。AV1のCPUエンコーダーは同梱FFmpegで使えるAOMで、SVTではありません。

元動画の縦横比を保ち、指定解像度に合わない部分には余白を追加します。最初の音声トラックを保存します。進捗表示と中止操作に対応し、元動画は上書きしません。焼き付けには時間がかかることがあります。

フレームレートは「ソースと同じ」、5 / 10 / 12 / 15 / 20 / 23.976 / 24 / 25 / 29.97 / 30 / 48 / 50 / 59.94 / 60 / 72 / 75 / 90 / 100 / 120 fpsから選べます。初期値は従来と同じ60 fpsで、選択はこのPCに保持します。23.976 / 29.97 / 59.94は、それぞれ24000/1001・30000/1001・60000/1001として扱います。

「ソースと同じ」はfps固定のフィルターを通さず、元動画のフレーム時刻を引き継ぎます。可変fpsも維持しますが、保存形式の時刻精度による丸めは生じる場合があります。MPEG-2/4ではこの項目を選択不可にするため、固定fpsを選んでください。固定fpsへ変えても動画の再生速度・音声・コメント時刻は変わりません。元映像のフレームは複製・間引きで調整し、コメントの位置は選択fpsで描画します。映像の動きを補間する機能ではありません。

画質の初期値は「High（高画質）」、エンコード速度は「標準」です。H.264（x264）の画質はHigh（CRF 18）／Medium（CRF 23）／Low（CRF 28）に対応し、ほかの方式はそれぞれのCRF・CQ・QPなどへ変換します。同じ段階でも、異なるエンコーダー間で画質や容量が同一になるわけではありません。FFV1はロスレスのため画質・速度の選択を無効にします。MPEG-2/4も速度の選択は使いません。高ビット深度の選択はSDRをHDRに変換する機能ではありません。選んだエンコーダーと設定はこのPCに保持します。

実装の各方式のオプションは [FFmpegのエンコーダー資料](https://ffmpeg.org/ffmpeg-codecs.html) と同梱バイナリの `-h encoder=...` で確認できます。

一般的な絵文字は、同梱の **Noto Color Emoji** で表示・画像化してカラーを保持します。確認欄とアプリ内の焼き付けで同じ絵文字フォントを使用し、OSへのフォントインストールは不要です。GIFはコメントの表示開始に合わせて再生します。

既存のASSだけを書き出す場合:

書き出した ASS ファイルは、字幕対応ソフトで利用できます。

例:

- [HandBrake](https://handbrake.fr/downloads.php) などで動画に焼き付ける
- ASS 対応プレイヤーで字幕として読み込む
- 動画編集ソフト側で追加素材として使う

通常の絵文字はASSにも文字として保存しますが、表示は再生・焼き付けソフトのフォント対応に依存します。**登録した独自画像やGIFはASSに埋め込めないため、ASS単体では元の文字列のままです。画像・GIFを反映する場合はアプリ内の焼き付けを使ってください。**

### Discord絵文字をURLから登録する

1. 「絵文字」タブの追加フォームへ、CSV・XMLに記録されている絵文字の文字列を入力する
2. 追加方法で「URL」を選び、表示されたURL欄へ画像・GIFそのもののHTTP / HTTPS URLを入力する
3. 「追加」を押す

拡張子のない画像URLや、クエリ付きの画像URLにも対応します。GIFは元のデータを保存し、アニメーションを保持します。取得した画像はアプリ内に保存するので、登録後のプレビュー・焼き付けでは元URLへの接続は不要です。同じ文字列で再登録すると画像を更新します。

一覧の「URLで変更」を押すと、保存済みの取得元URLを追加フォームへ表示します。URLを編集して「追加」を押すと画像とURLを更新します。URLは再起動後も保持し、取得に失敗した場合は以前の画像とURLを残します。ファイルから画像を変更した場合は、以前のURLを解除します。URLの保存に対応する前の登録分やファイルから追加した画像はURL欄が空になるため、一度URLを指定して更新してください。

PNG / JPEG / WebP / GIF、1件20MBまでです。DiscordのメッセージURLやWebページのURLではなく、画像を直接開くURLを指定してください。取得時にURLが期限切れ・非公開の場合は登録できません。

### 登録した絵文字の管理

CSV・XMLに実際に記録されている文字列を、そのまま追加フォームへ入力してください。登録後は画像・対応する文字列が一覧に追加され、各行の「画像を変更」「削除」で管理できます。同じ文字列の再登録でも画像を更新できます。画像は1件20MBまでです。登録画像はアプリのデータ領域へコピーされ、再起動後も保持されます。元ファイルの移動・削除には影響されません。

### YouTube独自絵文字を開発者側で同梱する

YouTube用の対応表は `assets/youtube/emoji-map.json` です。画像URLから取得する場合は `{"text": ":youtube_custom:", "url": "https://example.com/emoji.png"}` のように記載します。`npm start` / `npm run build` の前に未取得画像を自動ダウンロードし、`assets/youtube/images/` に保存します。GIFも対応しています。ローカル画像を使う場合は、従来どおり `file` に `images/example.png` のような相対パスを指定してください。

同じURLから画像を再取得したい場合は `npm run fetch-youtube-emojis` を実行します。取得済みの画像は同梱するため、配布後の起動・焼き付け時にはネット接続は不要です。詳しい手順は `assets/youtube/README.md` に記載しています。

再ビルドして配布すると、自動で変換・焼き付けに使用します。YouTube同梱絵文字はDiscord絵文字の一覧・登録件数には含めず、通常・拡大プレビューのサンプルの初期値に先頭2点を含めます。サンプルはプレビュー下の「サンプルテキスト」で自由に編集でき、改行や絵文字も反映します。編集内容は保持され、実際に書き出すコメントには追加しません。利用者によるインポート操作は不要です。開発者による画像の差し替えはアプリ更新で反映し、利用者が同じ文字列に独自画像を設定している場合はそちらを優先します。利用者が登録した上書き設定は一覧から管理でき、削除すると同梱画像に戻ります。

YouTube以外の共通同梱設定は `assets/emoji-map.json` でも指定できます（例: `assets/emoji-map.example.json`）。同梱画像は各設定JSONと同じフォルダー内、またはその子フォルダーへ配置してください。YouTube共通絵文字を同梱しています。追加したい独自絵文字は画像と文字列を対応表へ登録してください。

## 操作の流れ

1. [DiscordChatExporter](https://github.com/tyrrrz/discordchatexporter) で CSV をダウンロード
2. このアプリで CSV を読み込む
3. 字幕の見た目を調整する
4. ASS ファイルを書き出す
5. 動画に焼き付ける、または字幕として読み込む

## 開発・ビルド

```sh
npm ci
npm test
npm start
npm run build
npm run build-installer
```

FFmpegは依存関係のインストール時に取得し、配布アプリに同梱します。利用者がHandBrakeやFFmpegを別途インストールする必要はありません。

`npm start` / `npm run build` の前にFluent UIの画面も自動ビルドします。画面だけ更新する場合は `npm run build-ui` を実行してください。画面のソースは `renderer/workspace.jsx` と `renderer/workspace.css`、生成先は `assets/ui/` です。既存の変換・設定・画像管理処理と接続し、同じ入力要素をタブ間で保持しています。

画面構成は [electron-fluent-ui](https://github.com/oliverschwendener/electron-fluent-ui) の `FluentProvider` / `TabList` とデザイントークンの使い方を参考にしています。参考リポジトリ本体は実行・ビルドに必要ありません。

サードパーティーのライセンス・参照元は `THIRD_PARTY_NOTICES.md` を参照してください。

### テスト

```sh
npm test
npx electron tests/electron-smoke.cjs
```

画面のスクリーンショットも必要な場合は、UIテストに `--screenshots` を付けてください。画像は `dist/test-artifacts/` にだけ出力し、通常のテストではプロジェクト内に検証用画像を残しません。
