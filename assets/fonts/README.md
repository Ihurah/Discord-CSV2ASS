# Noto Color Emoji

`NotoColorEmoji.ttf` is the unmodified CBDT/CBLC color emoji font from the
official Google Fonts Noto Emoji project. It is loaded locally by the app for
Unicode emoji previews and rasterization during video export.

Project: https://github.com/googlefonts/noto-emoji
Font: https://raw.githubusercontent.com/googlefonts/noto-emoji/main/2D/fonts/NotoColorEmoji.ttf
License: https://raw.githubusercontent.com/googlefonts/noto-emoji/main/2D/fonts/LICENSE

The complete SIL Open Font License 1.1 is included as `NotoColorEmoji-LICENSE.txt`.
The original font's copyright metadata is preserved inside the font file.
Retrieved on 2026-10-25. Users do not need to install this font on their system.
