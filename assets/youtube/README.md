# YouTube独自絵文字の開発者設定

このフォルダーの画像と `emoji-map.json` は、アプリのビルド時にそのまま同梱します。
利用者が設定JSONを取り込む操作は不要です。ネット接続も不要です。

## 設定方法

1. `emoji-map.json` の `emojis` 配列に、コメント内の文字列と画像のURLを追加する。
2. `npm start` または `npm run build` を実行する（未取得のURL画像は事前に自動取得）。
3. サンプルテキスト・変換確認欄で確認する。
4. 配布する場合はアプリとインストーラーを再ビルドする。

例（サンプル名なので、実際の文字列・画像名に置き換えてください）:

```json
{
  "emojis": [
    { "text": ":youtube_from_url:", "url": "https://example.com/emoji.png" },
    { "text": ":youtube_custom:", "file": "images/youtube_custom.png" },
    { "text": ":youtube_animated:", "file": "images/youtube_animated.gif" }
  ]
}
```

`text` はCSV・XMLのコメントに記録された文字列と完全一致する必要があります。
コロンの有無も含めてそのまま指定してください。複数の別名を同じ画像に対応させる
場合は、別々の項目を追加して同じ `url` または `file` を指定できます。

`url` には画像・GIFそのもののHTTP / HTTPS URLを指定してください。Webページの
URLには対応していません。PNG / JPEG / WebP / GIFを、1ファイル20MBまで取得できます。
取得した画像は `images/url-...` に保存します。GIFは元のアニメーションを保持します。
同じURLは再取得せず、複数の文字列でも画像を共有します。URLを変更した場合は
別の画像として取得します。`url` と `file` の両方を指定した場合は `url` を優先します。

同じURLの画像を更新し直す場合や、まとめて再取得する場合:

```sh
npm run fetch-youtube-emojis
```

未取得の画像だけを手動取得する場合:

```sh
npm run prepare-youtube-emojis
```

配布アプリは同梱された画像だけを読み込みます。起動時や焼き付け時にURLへ
アクセスしません。取得済みなら開発環境でもオフラインで起動・ビルドできます。
取得した `images/url-...` ファイルも対応表と一緒に管理・配布してください。

`file` はこのJSONを基準とした相対パスです。このフォルダーの外のファイルは
指定できません。PNG / JPEG / WebP / GIFに対応し、1ファイル20MBまでです。

## 更新と利用者の設定

同梱設定は利用者の設定とは別に読み込みます。開発者が対応表や画像を変更して
配布し直すと、新しい同梱設定が読み込まれます。利用者が同じ文字列を登録して
いる場合は、その利用者設定を優先します。

YouTubeの同梱項目はDiscord絵文字の一覧や登録件数には含めません。
通常・拡大プレビューのサンプルテキストの初期値には、YouTube絵文字の先頭2点を含めます。
プレビュー下の入力欄で自由に編集でき、編集内容は次回起動時にも保持します。
利用者が同じ文字列で画像を追加すると上書き設定を作成でき、この設定は一覧から
管理できます。上書き設定を削除すると同梱画像に戻ります。

チャンネルのメンバーシップ絵文字なども、同じ仕組みで設定できます。
追加の画像と対応する文字列は自分で用意してください。現在はサンプルとして
`:face-blue-smiling:` と `:face-red-heart-shape:` の2点を収録しています。
画像の取得元は `SOURCES.md` に記録しています。

登録したYouTube絵文字は、変換確認欄に対応する文字列を入力して確認できます。
